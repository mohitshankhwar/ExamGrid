# Exam Gride
### Exam Seating Arrangement System

**Introduction**

Exam Gride is a web-based application designed to simplify examination seating arrangements and reduce manual work in educational institutions.

**Objectives**
- Manage student records.
- Manage examination details.
- Manage classrooms and seating capacities.
- Generate examination seating arrangements.

**Key Modules**
1. Student Management — Add students and view their records.
2. Exam Management — Add examinations and view exam details.
3. Room Management — Add classrooms and manage their seating capacities.
4. Seating Arrangement — Generate seating plans using student and room data.

**User Roles**
- Admin/Teacher: Manage students, examinations, classrooms, and seating arrangements.

**Technologies Used**
- Frontend: HTML, CSS
- Backend: Java, Servlets, JSP
- Database: MongoDB
- IDE: Eclipse IDE for Enterprise Java and Web Developers
- Version Control: Git and GitHub

**Team Structure**
- Member 1: Student Management
- Member 2: Exam Management
- Member 3: Room Management
- Member 4: Seating Arrangement

**Expected Outcome**

A web application that helps teachers organise examination seating and enables students to find their assigned seats easily.
